Simulasi Keamanan Transmisi & Penyimpanan Data Lokal

Mendemonstrasikan bagaimana data sensitif dienkripsi di sisi server sebelum disimpan ke SQLite, sementara lalu lintas jaringan HTTP polos pada interface loopback tetap dapat diamati oleh packet sniffer.

1. Input & Simpan Data (Enkripsi)

Data dikirim dalam format JSON via POST /api/secrets, lalu dienkripsi dengan {{ algorithm }} menggunakan kunci di .env sebelum masuk ke database.

2. Baca Data (Dekripsi Server)

GET /api/secrets mengambil ciphertext dari SQLite, mendekripsinya, dan mengembalikan plaintext.
